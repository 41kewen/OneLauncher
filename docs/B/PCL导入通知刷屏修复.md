# PCL 导入通知刷屏修复

## 问题

Issue #10 中的“操”并非程序输出脏话，而是通知中的“操作”被窄宽度拆成两行。原进度回调为每个文件创建持续五秒的独立通知，数千个文件的通知堆叠后遮挡实例选择和启动按钮；长资源哈希进一步导致换行。

## 修改

只在 `Meta` 且没有文件总数的阶段信息到来时显示简短通知，不再为下载或复制每个文件创建通知。移除包含“操作:”和长文件名的通知模板及逐文件调试输出；保留开始、成功和失败提示。

本 PR 不修改导入器、加载器选择、依赖迁移或 Forge 安装逻辑。

## 验证

在 Windows x64、.NET SDK 10.0.302 上独立构建桌面项目成功，0 错误；已有项目警告仍存在。静态检查确认文件级进度在发送通知前返回，完成提示仍在导入方法成功返回后发送。

本次 PR 拆分没有再执行桌面导入录屏；不把构建成功当作完整 UI 验收。
