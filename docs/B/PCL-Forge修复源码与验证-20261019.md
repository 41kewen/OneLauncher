# PCL 导入与 Forge 下载／处理器修复

本分支基于 OneLauncher `831e23a4f5d44f0c42722aa8ca750d904f5b02a6`，保存已完成的局部修复及回归测试。不是完整 Forge/NeoForge 安装系统重构，也不宣称原仓库其他缺陷已经全部解决。

## 修复内容

- PCL 导入按完整版本清单迁移，而不是重新选择默认加载器。通过 Maven 库坐标和 FML 参数识别 Forge/NeoForge，保留精确版本；解析父版本并拒绝继承循环。
- 导入清单保存到实例独立的 `launch.json`；启动使用原 JVM/game 参数，不叠加共享加载器配置。保留旧非导入启动入口兼容性。
- 导入前校验已有缓存和源文件；缺失可下载资源才联网，生成型文件缺失则明确失败。Mods、配置和存档按源内容迁移，不删除或移动源实例。
- 导入采用 staging 发布和登记，失败／取消撤销本次实例；路径检查拒绝越界与链接。首页仅提示阶段进度，避免数千条通知遮挡窗口。
- Forge/NeoForge 依赖和下载列表按规范化目标路径去重；共享异步路径锁和随机临时文件避免同进程下载冲突，完成计数仅统计成功的唯一目标。
- 对明确支持的客户端 DOWNLOAD_MOJMAPS 原始下载交由启动器下载器处理，校验长度与 SHA1；未知变体保留原 Java 执行语义。
- Java 安装处理器使用 ArgumentList，完整保存 stdout/stderr，等待双流收尾后判断退出；取消结束进程树并传播 Canceled，错误附日志上下文。

```powershell
dotnet build ConsoleTest/ConsoleTest.csproj -c Debug
dotnet ConsoleTest/bin/Debug/net10.0/ConsoleTest.dll --pcl-import-regression-tests
dotnet ConsoleTest/bin/Debug/net10.0/ConsoleTest.dll --download-regression-tests
dotnet ConsoleTest/bin/Debug/net10.0/ConsoleTest.dll --processor-regression-tests
```

测试入口位于 Init.Initialize 之前，不读取日常账号配置。10组导入、8组下载、6组处理器，共24组回归，覆盖精确组件／参数、真实子进程argv、缓存损坏、缺失生成文件、注册失败、路径安全、并发锁、重试／取消、Mojang映射、输出EOF与非零退出诊断。
