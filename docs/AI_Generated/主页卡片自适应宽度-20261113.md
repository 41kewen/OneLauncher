# 主页卡片自适应宽度

## 用意

默认主页的四张卡片原先固定为 385 像素宽。窗口最大化时，列表项虽然铺满左侧内容区，内部卡片仍然以固定宽度居中，造成大片留白。此次修复让默认主页卡片随可用宽度伸展，右侧快速启动区继续使用 300 像素宽。

## 实现

- `OneLauncher/Views/Pages/Home.axaml`：四张卡片根 Border 使用 `home-section-card` 类，移除本地固定 Width。默认主页由现有列表项的 Stretch 对齐铺满内容区；外层 ScrollViewer 禁用横向滚动，使内容按视口宽度布局。
- 魔法按钮主页通过 `ScrollViewer.home-sections.magic Border.home-section-card` 选择器设置 Width 为 385，继续为右侧按钮保留空间。
- `ConsoleTest/agent_test/OneLauncher.RegressionTests/MagicHomeUiChecks.cs`：现有检查改用卡片类名定位根 Border，避免将固定 Width 当成卡片身份。

此次只修改视图尺寸规则，不涉及 ViewModel、业务命令或反射，兼容现有 AOT 编译方式。此修复取代 `UI_FI.md` 中关于默认主页卡片固定为 385 像素的旧布局约定；魔法按钮主页仍采用固定宽度。

## 后续扩展

新增主页板块时，在根 Border 使用 `home-section-card` 即可复用两种主页样式的宽度规则。卡片圆角裁剪、阴影、主题颜色与可见性仍由现有结构控制。
