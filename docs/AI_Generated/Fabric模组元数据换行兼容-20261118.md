# Fabric 模组元数据换行兼容

## 问题

部分模组的 `fabric.mod.json` 在 `description` 等字符串中包含实际换行，或使用反斜杠后接实际换行。这两种写法不符合 JSON 标准，`System.Text.Json` 会抛出 `JsonException`，随后 `ModInfoGetter` 返回 `null`，导致模组无法识别。合法写法是在 JSON 字符串中使用 `\n` 或 `\r\n` 转义。

## 实现

修改 `OneLauncher.Core/DefaultComponent/Resource/Mod/Manager/FabricModInfoHelper.cs`：先按原有方式严格解析；仅在 `JsonException` 时重新读取条目，在内存中转义字符串内的实际 CR/LF，并去掉紧接实际换行的无效反斜杠，再重试解析。描述仍保留换行，不修改磁盘上的模组 JAR。

扫描器跟踪字符串边界，跳过已有转义，保留字符串外的排版换行。其他格式错误仍由 JSON 解析器拒绝。读取条目的流及时释放，两次解析均使用 `FabricModJsonContext` 的源生成类型信息，兼容 AOT。

## 扩展与验证

兼容范围仅限字符串换行。若未来支持其他非标准元数据写法，应在严格解析失败后的路径中添加明确规则，并避免全局替换改变合法转义的含义。

按项目要求，本次小范围修复未运行测试；已检查 LF、CRLF、反斜杠续行、已有转义及字符串边界处理逻辑。
