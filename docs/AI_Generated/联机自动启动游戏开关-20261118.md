# 联机自动启动游戏开关

设置 → 游戏启动新增“联机时自动启动游戏”，通过 `AppSettings.AutoLaunchGameOnPowerPlay` 保存到现有配置。默认值为 `true`，旧配置缺少该字段时保持自动启动行为；沿用现有 JSON 源生成序列化机制，兼容 AOT。

设置页通过异步保存更新配置，保存期间禁用开关，失败时恢复原值并显示异常。联机 Pane 工厂注入 DBManager，使创建、加入与连接成功回调直接读取当前配置。

关闭开关时，创建房间仍需选择实例以生成包含版本号的房间码，但不启动游戏。加入房间只建立连接并显示本地地址，无需查找已安装实例，也不修改默认实例；用户手动启动游戏并连接该地址。MCT 房间仍仅建立连接。

自动启动的连接回调在触发后或断开连接时解除订阅，避免后续重新加入房间触发旧回调。按钮文字根据设置显示是否启动游戏。

改动涉及配置模型、设置页 ViewModel/视图、联机 Pane ViewModel/视图及工厂。后续如需分别控制创建与加入，可在 AppSettings 扩展独立字段并分别应用到两条流程，联机服务接口无需调整。

按本次项目指令，此项小改动不运行构建、游戏启动或测试；已进行源代码与绑定检查。
