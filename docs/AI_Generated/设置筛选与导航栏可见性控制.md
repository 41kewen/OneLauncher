# 设置筛选与导航栏可见性控制

日期：2026-10-22。

## 行为与默认值

设置标题下新增 ComboBox，选项为全部设置、界面、游戏启动、下载、运行环境。运行环境保留独立板块；关于始终显示。默认选择全部设置，筛选状态只存在于页面 ViewModel，不写入配置。

界面板块使用“控制左侧导航栏页面”按钮代替旧的两个 ToggleSwitch。按钮通过 `Button.Flyout` 打开浮窗，包含版本管理、游戏数据、服务器收藏、下载管理、资源检索、账户管理六个复选项，以及下方的“保存并应用”。主页、设置固定显示。

新配置和缺失字段使用默认值：版本管理隐藏，其余页面显示。旧配置中明确保存的服务器收藏和版本管理选择继续保留，不在升级时重置。

## 文件与职责

- `OneLauncher/Views/settings.axaml`：筛选 ComboBox、四个板块的可见性绑定、导航浮窗和复选框模板。
- `OneLauncher/Views/ViewModels/SettingsPageViewModel.cs`：筛选派生属性、导航编辑副本、刷新列表和异步保存命令。
- `OneLauncher/Views/ViewModels/NavigationVisibilityItem.cs`：页面标识、名称和勾选状态；不直接写配置。
- `OneLauncher/Views/Controls/SettingsFlyout.cs`：在原生 Flyout 上提供 `IsEditing` 双向绑定和 `IsBusy` 绑定，只处理视觉生命周期。
- `OneLauncher/Views/MainWindow.axaml.cs`：应用导航可见性，当前页面被隐藏时切回主页，阻止选中隐藏入口。
- `OneLauncher.Core/Global/ModelDataMangers/DBManager.cs`：六个导航配置及默认值，保留既有 JSON 源生成序列化方式。
- `OneLauncher.Core/Global/ModelDataMangers/GameDataManger.cs`：默认实例查询兼容空实例、失效映射及非数字版本 ID。

根据用户要求，`settings.axaml.cs` 没有修改。没有新增浮窗消息类，也没有修改桌面启动项目。

`Button.toolbar-action StackPanel` 现有样式会匹配浮窗内部的子控件，因此外层导航控制按钮使用 `item-action`，避免复选框被排成横向。

## 编辑、保存和关闭

打开时，SettingsFlyout 将 `IsEditing` 设为 true，ViewModel 据此从配置重新创建列表。勾选只修改编辑副本；点击外部或按 Escape 关闭后，再打开会重读已保存配置。

保存命令一次更新六个配置，等待 `DBManager.Save()`。保存期间禁用复选项、防止重复执行和意外关闭。成功后配置事件通知主窗口刷新，并通过 `IsEditing = false` 关闭浮窗；失败时恢复内存中的原选择与本次新增的服务器，保留编辑副本并交给 OlanExceptionWorker 显示错误。

保留原有默认 Hypixel 服务器行为，但只在保存且服务器收藏启用、收藏列表为空、存在默认游戏实例时执行。空实例状态仍可正常保存导航选择，不自动创建服务器。

## 扩展方式

增加筛选板块时，同时扩展 SettingsCategories、对应的可见性派生属性及变更通知，并在 AXAML 绑定新板块。关于不参与筛选。

增加导航入口时，在 AppSettings 声明兼容旧配置的默认值，扩展 NavigationPage、CreateNavigationItems、ApplyNavigationItems 和 MainWindow.ApplyUiSettings。主页、设置继续不提供关闭字段。
