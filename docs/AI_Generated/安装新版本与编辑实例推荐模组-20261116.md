# 安装新版本与编辑实例的一键安装推荐模组

## 行为

- 安装新版本：安装选项新增“一键安装推荐模组”，默认不勾选，仅在选择 Fabric、Quilt、Forge 或 NeoForge 时可用。版本安装和实例登记成功后，对本次创建的每个模组实例分别启动推荐模组任务，原版实例跳过。
- 编辑实例：新增“一键安装推荐模组”按钮，直接为当前实例安装；原版实例禁用按钮并提示支持的加载器。同一按钮的异步命令执行期间禁止重复点击。
- 推荐模组任务独立显示在任务中心，可以取消；取消或失败保留已创建的实例。关闭 Pane 不取消后台任务。

## 实现

`OneLauncher/Codes/RecommendedModsInstallation.cs` 统一加载器判断、任务创建、后台调用、进度更新、取消和异常提示。新增游戏数据入口也复用该流程，避免三个入口分别维护通知和错误处理。

实际下载仍调用已有 `ResourceInstallerService.InstallRecommendedMods`：读取 `DefaultSettings.RecommandedMods` 的 Modrinth 项目 ID 清单，根据实例 Minecraft 版本及加载器筛选，下载必要依赖，并按下载路径去重。没有兼容版本的推荐项由现有后端跳过。前端不新增固定模组清单或 JSON 模型，保持 AOT 兼容。

安装新版本原先通过 `List.ForEach(async ...)` 保存实例，无法等待登记完成；改为逐项等待保存，保证设置默认实例和推荐模组安装发生在实例登记成功后。推荐模组失败不改变已完成的版本安装任务状态。

## 文件与扩展

- `OneLauncher/Views/Panes/DownloadPane.axaml`、`EditGameDataPane.axaml`：复用现有 Pane 样式增加入口和说明。
- `OneLauncher/ViewModels/Panes/DownloadPaneViewModel.cs`：安装选项状态和安装成功后调度。
- `OneLauncher/ViewModels/Panes/EditGameDataPaneViewModel.cs` 及其 Factory：通过构造函数注入现有安装服务和任务管理器，提供异步安装命令。
- `OneLauncher/ViewModels/Panes/NewGameDataPaneViewModel.cs`：复用统一的安装流程。
- `OneLauncher/Codes/RecommendedModsInstallation.cs`：前端共用的推荐模组任务流程。

后续新增入口可复用 `InstallAsync`；更新推荐清单继续使用已有配置。安装接口当前只报告文件序号，没有总数，任务进度显示当前文件，并在成功后设置为 100%。
