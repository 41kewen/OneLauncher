# 任务中心事件刷新与实例生命周期

## 代码用意

移除任务中心每 500ms 检查任务队列的轮询方式，改为任务创建事件驱动更新。取消首页对 TaskCenterPaneViewModel 的缓存，每次打开任务中心由工厂创建新实例。

## 更新逻辑

- TaskManager.CreateTask 在任务加入 TaskQueue 后触发 `event Action? OnTaskCreate`，订阅者可以读取包含新任务的完整队列快照。事件在创建任务的调用线程触发。
- TaskCenterPaneViewModel 构造时先订阅事件，再通过 RefList 初始化列表。收到事件后切换到 Avalonia UI 线程，读取完整队列快照并替换 Tasks，最新任务位于顶部。
- RefList 在替换列表前释放旧 TaskInstanceItemViewModel 的事件订阅。任务进度、完成、失败、取消仍通过 TaskInstance 的现有事件更新，不需要定时刷新。
- HomePageViewModel 每次打开任务中心创建新实例；面板关闭（包括 IsPaneShow 双向绑定关闭）或 PaneContent 被替换时，释放旧任务中心。释放只解除订阅，不取消实际任务。
- 已释放的面板和列表项忽略排队中的刷新回调，避免关闭后重新建立订阅。
- TaskCenterPaneViewModelFactory 保持无面板状态的单例工厂，Create 每次返回新实例。

## 未来扩展

后续新增任务删除或清空功能时，应在 TaskManager 提供相应变更事件，由前端调用同一 RefList 刷新。直接修改 TaskQueue 不会触发 OnTaskCreate，创建任务应统一调用 CreateTask。新的面板宿主必须在关闭或替换任务中心时调用 Dispose。
