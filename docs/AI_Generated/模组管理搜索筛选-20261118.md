# 模组管理搜索筛选

## 修改文件

- `OneLauncher/ViewModels/Panes/GameDataModsManagerPaneViewModel.cs`
- `OneLauncher/Views/Panes/GameDataModsManagerPane.axaml`

## 行为与实现

模组管理侧栏在标题下方新增搜索框，使用现有 `search-field` 样式。输入变化立即筛选，无需重新扫描文件；搜索忽略大小写及首尾空白，匹配名称、ID、显示描述或文件名。清空输入恢复完整列表。

ViewModel 的 `AllMods` 保存后端扫描所得的全部模组项，`Mods` 保存当前显示列表。刷新重新加载 `AllMods`，并自动按当前搜索文字生成 `Mods`。两个列表引用相同的 `InstanceModItem`，筛选过程中保留单项启用状态。

`InstanceModItem` 根据后端现有的“未知标识符”判断无法识别的模组。其 `Description` 返回后端记录的文件路径，`HasVersion` 为 false，前端隐藏整个版本行。描述增加悬浮提示，便于查看省略后的完整路径。已识别模组仍显示原描述和非空版本。

## 扩展与验证

新增搜索字段时，在 `FilterMods` 中增加匹配条件即可。未来后端若引入专门的识别状态字段，可替换 `IsUnknown` 的判断而无需改动视图。使用 CommunityToolkit 生成属性通知和 Avalonia 编译绑定，无新增反射或动态代码。
